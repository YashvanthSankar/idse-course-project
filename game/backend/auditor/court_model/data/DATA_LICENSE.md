# Data licence

The JSON files here are a database derived from Development Data Lab's judicial data
(eCourts case records, 2010–2018), <https://www.devdatalab.org/judicial-data>.

They are made available under the **Open Database License (ODbL) v1.0**, the licence that
ships with the source data: <https://opendatacommons.org/licenses/odbl/1-0/>. Any database
derived from them must also be shared under ODbL, with this attribution.

They hold only aggregates, the model's input options, and 300 de-identified 2017 Tamil Nadu cases
(kind of case, district, filing date and outcome; no case numbers, names or ids).
