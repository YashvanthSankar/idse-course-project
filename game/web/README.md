# game/web: the website

Next.js (App Router) app that serves both parts of the project on one domain,
[otlr.vercel.app](https://otlr.vercel.app). The project overview is in the [root README](../../README.md).

| Path | What it is | Code |
|---|---|---|
| `/` | OUTLIER title screen | `app/page.tsx`, `components/title/` |
| `/office`, `/case/[caseId]`, `/case/[caseId]/verdict` | the game: office, investigation and corkboard, verdict | `components/office/`, `case/`, `board/`, `verdict/` |
| `/career` | Career Mode | `components/career/` |
| `/host`, `/host/[code]`, `/host/[code]/autopsy`, `/play/[code]` | Class Mode: the host screen, the class autopsy, the phones | `components/host/`, `autopsy/`, `play/` |
| `/profile/[playerId]` | a player's detective card | `components/profile/` |
| `/model` | the court case duration model: home | `components/model/Home.tsx` |
| `/model/explore` | test the model: choose a case, press Analyze | `components/model/Predict.tsx` |
| `/model/analytics` | what the court data shows | `components/model/Analytics.tsx` |
| `/model/pipeline` | the whole pipeline notebook, step by step | `components/model/Pipeline.tsx`, data in `public/pipeline/` |

The `/model` pages have their own look (`app/model/model.css`, `app/model/layout.tsx`); the game's
effects are off there. `public/pipeline/` is generated by `pipeline/scripts/export_notebook.py`;
don't edit it by hand.

## Run

```bash
pnpm install
NEXT_PUBLIC_API_URL=http://localhost:8000 pnpm dev --port 3200
```

`NEXT_PUBLIC_API_URL` is the FastAPI backend (`game/backend`, see the root README). The game calls it
directly; the model pages call `/model-api/*`, which `next.config.ts` rewrites to
`$NEXT_PUBLIC_API_URL/api/model/*`, so visitors only talk to this site.

## Test

```bash
pnpm test        # Vitest unit tests
pnpm e2e         # Playwright end to end; starts `pnpm dev` on port 3200, needs the backend running
pnpm lint
```

## Deploy

Vercel, from this folder:

```bash
vercel deploy --prod --build-env NEXT_PUBLIC_API_URL=https://<the backend's HTTPS address>
```

Deploy the backend first when the API changed.
